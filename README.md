# Personal Services Website - README

## Overview
This is a personal website built with Django that showcases my professional services including:
- Data Analysis
- Web Development
- Graphic Design
- Technical Support

The site serves as both a portfolio of my work and an advertising platform for my freelance/consulting services.

## Features
- **Service Catalog**: Detailed pages for each service I offer
- **Contact Form**: For potential clients to reach out
- **Responsive Design**: Works on mobile, tablet and desktop
- **Admin Dashboard**: Easy content management via Django admin

## Technologies Used
- **Backend**: Django (Python)
- **Frontend**: HTML5, CSS3, JavaScript 
- **Database**: SQLite
- **Hosting**: Render (https://creativetech.onrender.com/)
